# Uncertainty-Aware AI for Medical Diagnosis

## Overview

This project develops a machine learning model to predict diabetes risk using medical data.
The model also estimates prediction confidence to highlight uncertainty in AI-based medical diagnosis.

## Features

* Loads medical dataset
* Trains a machine learning model
* Predicts diabetes risk
* Displays prediction confidence

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Algorithm

Random Forest Classifier

## Project Structure

uncertainty_medical_ai

* data
* results
* medical_ai_model.py

## Output

The model predicts diabetes risk and provides confidence scores for predictions.

## Applications

This project demonstrates how machine learning can assist in healthcare diagnosis while showing model uncertainty.
