# Research Paper Knowledge Graph Generator

## Overview

This project constructs a knowledge graph from research paper metadata to visualize relationships between different AI research topics.

## Features

* Extracts topics from research papers
* Builds a network graph of research domains
* Visualizes connections between AI fields

## Technologies Used

* Python
* Pandas
* NetworkX
* Matplotlib

## Project Structure

knowledge_graph_generator

* data
* results
* knowledge_graph.py

## Output

The program generates a network graph representing connections between AI research areas.

## Applications

This project helps analyze how different AI research fields are interconnected.
